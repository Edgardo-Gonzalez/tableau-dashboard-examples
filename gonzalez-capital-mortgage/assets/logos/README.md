# Logo Assets

Store Gonzalez Capital Mortgage logo files here for use in Tableau reports and dashboards.

| File | Intended use |
| --- | --- |
| `logo-horizontal-lockup-trimmed.png` | Tightly cropped horizontal logo for Tableau and report headers |
| `logo-primary-landscape-trimmed.png` | Tightly cropped landscape primary logo |
| `logo-primary-stacked-trimmed.png` | Tightly cropped portrait logo for title pages and documents |
| `logo-monogram-gcm-trimmed.png` | Tightly cropped GCM mark for small-format placements |
| `app-icon-gcm-trimmed.png` | Tightly cropped application or browser icon |
| Original logo PNGs | Full-canvas source assets, retained for other uses |
| `watermark.png` | Subtle background watermark |
| `letterhead-breaking-bad-white-residence.png` | Letterhead template with the fictional White-residence address from *Breaking Bad* |
| `letterhead-sopranos-residence.png` | Letterhead template with the fictional Soprano-residence address from *The Sopranos* |

Letterheads and the watermark retain their whitespace because it is part of their
intended layout. For future additions, prefer transparent-background PNG or SVG
assets where possible.
